# المنافس لتجهيز الأندية الرياضية | Almunafes Gym Equipment

منصة ويب متكاملة ولوحة تحكم إدارية لتجهيز الأندية الرياضية ومراكز اللياقة البدنية بأحدث المعدات والأجهزة الرياضية التجارية.

## أبرز المميزات
- **واجهة عرض احترافية:** استعراض شامل لأقسام الأجهزة (الكارديو، القوة، الأوزان الحرة، والتدريب الوظيفي).
- **لوحة تحكم متكاملة (`/admin`):** إضافة وتعديل المنتجات، العلامات التجارية، والعروض بسهولة دون الحاجة لخبرة برمجية.
- **واجهة برمجية (`API`):** ربط مباشر لتغذية تطبيق الهواتف الذكية (Android / iOS) بالمنتجات والصور تلقائياً.
- **نظام طلب عروض الأسعار:** استقبال طلبات تجهيز الأندية واستفسارات العملاء مباشرة.

## التقنيات المستخدمة
- **الواجهة الأمامية:** HTML5, CSS3, JavaScript (تصميم متجاوب يدعم اللغة العربية RTL).
- **الواجهة الخلفية:** PHP & JSON Data Storage.
